# AI policy

We support using AI tools, including large language models, when contributing
to Z-Wave JS projects. You are responsible for every contribution you submit.
Maintainers are responsible for every contribution they merge and release.
Z-Wave JS holds a high bar for all contributions.

Maintainers dedicate their time and expertise to reviewing contributions.
Submitting AI-generated content that you have not personally reviewed and
understood wastes that time and will not be accepted.

## Autonomous agents

**We do not allow autonomous agents to contribute to Z-Wave JS projects.**
We will close any pull requests or issues that we believe were created
autonomously. We may mark automated comments as spam. This includes
contributions that bypass the provided issue or pull request templates.

## Communication on issues, pull requests, and code reviews

You may use AI tools to help you write. However, do not let tools post
unreviewed content on your behalf. Keep responses to the minimum needed to
communicate your intent. We may hide comments that we believe are unreviewed
AI output.

If you open a pull request, you must be able to explain the proposed changes in
your own words. This includes the pull request description and responses to
questions. If you use AI to help generate the pull request summary, you must
review it for technical accuracy.

**Do not use AI to generate answers to questions from maintainers.** You must
understand and be able to explain your own work. Using AI to improve grammar or
clarity is fine. The substance of your responses must be your own.

If you include context from an interaction with AI in a comment, put it in a
quote block using `>` and disclose that it came from AI. Add your own commentary
that explains why the context is relevant and what it means. Do not share long
snippets.

## Non-native English speakers

We understand that AI is useful when communicating in a language that is not
your first language. You may use AI to improve the grammar or clarity of text
you wrote yourself. If you use AI to translate your comments, make sure the
translation accurately reflects your intent. Including your original text in a
details block shows the effort behind your contribution. It also helps
maintainers verify the translation and keeps the conversation readable.

## Code and documentation contributions

AI can help write code and documentation. Z-Wave JS projects require a human
reviewer who understands all work produced by AI.

You must review and understand every contribution before submitting it. You
must be able to explain every code and documentation change in a pull request.
We will close pull requests that appear to contain unreviewed AI output without
reviewing them.

## Our use of AI

Some Z-Wave JS projects use AI tools to assist with code reviews, issue
triaging, reporting, and other project management tasks. These tools may leave
comments on pull requests or issues. Like any automated tooling, their comments
can be incorrect.

Treat an AI tool's comment like any other review comment. If you believe it is
incorrect, say so. A brief explanation is sufficient. Maintainers always have
the final say. Ask a maintainer if you are unsure.

## Enforcement

We will close contributions that do not follow this policy. Repeated violations
may result in being blocked from contributing to Z-Wave JS projects. If you
believe your contribution was closed in error, contact a maintainer to discuss
it.

This policy is adapted from the
[Home Assistant AI policy](https://developers.home-assistant.io/docs/ai_policy),
published by the
[Open Home Foundation](https://www.openhomefoundation.org/).
